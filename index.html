01 · Final year project

Accessible Navigation

Computer vision · AR · iOS

A pedestrian app for wheelchair, walker and cane users that cares what the pavement is like, not just which way to turn. It plans around barriers, spots hazards through the camera and draws the route onto the ground in AR.

  • Four mobility profiles, each sending different restrictions to the router, with barrier screening from OpenStreetMap data.
  • AR guidance built as 3D geometry inside the ARKit scene, anchored with ARCore Geospatial, with a compass fallback.
  • On-device hazard detection at 10 Hz using a fine-tuned YOLO26n model exported to Core ML.
  • Voice cues, text scaling, dark mode and screen-reader labels throughout.

02 · Personal project

Qtic · Event Ticketing

Full-stack · Serverless · Payments

A multi-role ticketing platform where organizers submit events and admins approve them, with no code changes needed for new events. Built for my dad's events business.

  • Role-based access for organizers, admins and gate scanners, enforced by Firestore security rules with automated tests.
  • Organizer sign-up with email OTP verification and an admin approval flow, with transactional emails for each state.
  • Billplz payments and Google Maps on event pages, called through Cloud Functions with keys held in Secret Manager.
  • QR e-tickets, a scanning page for entry, and a GitHub Actions pipeline that deploys the app and functions.

03 · Currently building

Nutrition Tracker

Native iOS · AI assistant

A native iPhone app for tracking calories and macros against daily ranges. I built it because I wanted a tracker without a subscription, and because no app I tried could tell me what to eat with the allowance I had left.

  • An assistant using OpenAI's Responses API with function calling and web search to suggest meals, log food and add notes.
  • Every proposed change becomes a draft that I review and confirm, so nothing AI-generated is saved silently.
  • Barcode lookup through Open Food Facts with a local cache, plus trends and a calendar of past days.
  • SwiftData with a versioned migration plan, JSON backup and restore, and a GitHub Actions build.

04 · Group project

Malaysia Photovoltaic Energy Predictor

Machine learning · GIS · TypeScript

A map-based web app that predicts solar energy yield across Malaysia. A model trained by our team runs inside the browser, so predictions need no backend.

  • In-browser XGBoost inference over 8,760 hours of weather data to predict solar yield.
  • Custom HTML5 Canvas renderer with viewport culling, so large power grids and AHP-scored heatmaps stay smooth.
  • Trained on Google Colab. When free-tier sessions kept dying, we checkpointed progress to Drive and resumed.
  • Google Maps integration to explore locations on the map.

05 · My first app

Pet Breeder Genealogy Tracker

Progressive web app · Firebase

The very first thing I built. A hamster business with almost 200 animals needed a way to record each one, trace bloodlines and check whether two hamsters can be bred safely.

  • Visual family trees that show lineage at a glance.
  • A breeding check that blocks pairs sharing an ancestor within three generations (try the demo).
  • Real-time sync with Firebase, protected by device authorization.
  • Built as a PWA so it installs and works on iPhones without an App Store release.
